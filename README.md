# sz5ylv1a's userstyles

A couple userstyles that I've made and decided to make public. Some are unfinished though, but that'll change over time.

## Styles

- [GD Browser Custom Background Image](https://github.com/sz5ylv1a/userstyles/tree/main/styles/GDBrowserCustomBG) - Lets you put your own custom background image for [GD Browser](https://gdbrowser.com) and its many instances for private servers.
- [Skribbl.io Transparent Bar](https://github.com/sz5ylv1a/userstyles/tree/main/styles/SkribblTransparentBar) - Changes out [skribbl.io](https://skribbl.io/)'s top bar to a transparent one
